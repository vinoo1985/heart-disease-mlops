# Dataset Attribution & License

The data shipped with this repository under `data/raw/` and
`data/processed/` is the **Heart Disease (Cleveland)** subset of the UCI
Machine Learning Repository. It is redistributed here unmodified for the
sole purpose of academic reproducibility.

## Source

- Repository: UCI Machine Learning Repository
- Dataset:    Heart Disease (Cleveland processed)
- URL:        https://archive.ics.uci.edu/dataset/45/heart+disease
- File:       `processed.cleveland.data` (303 rows × 14 columns)

## Use terms

The UCI Machine Learning Repository makes its datasets freely available
for academic and non-commercial research. Any redistribution must
preserve attribution to the original donors. This repository complies
with that requirement by:

1. Linking to the UCI source page in `README.md` and in
   `notebooks/01_eda.ipynb`.
2. Reproducing the citation above in this file.
3. Leaving the raw file `data/raw/processed.cleveland.data` byte-for-byte
   identical to the UCI release.
